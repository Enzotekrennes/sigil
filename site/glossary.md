# Glossary / Glossaire

Terms of the Sigil documentation, English → French. The French column matches the labels
of the French interface (`src/app/strings.fr.ts`). Use these terms in every page, and add
any new term here before using it. Identifiers, file names, commands and code are never
translated.

Termes de la documentation de Sigil, anglais → français. La colonne française reprend les
libellés de l'interface française (`src/app/strings.fr.ts`). Employer ces termes dans
chaque page et ajouter ici tout nouveau terme avant de l'utiliser. Identifiants, noms de
fichiers, commandes et code ne se traduisent jamais.
